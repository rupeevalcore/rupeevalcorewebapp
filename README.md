# RupeeValcore Web Platform

Premium Financial Literacy and AI Education Platform for Schools, Colleges, Corporates and Individuals.

---

## Overview

RupeeValcore is an education-first platform focused on improving financial awareness through structured learning experiences.

The platform serves:
- Schools
- Colleges
- Corporates
- Working Professionals
- Families
- Individual Learners

The platform also contains a dedicated AI Education division operating independently from Financial Literacy.

---

## Core Principles

**Education First.**  
**No Products.**  
**No Commissions.**  

The platform focuses exclusively on education and awareness and does not provide:
- investment advice
- stock recommendations
- mutual fund recommendations
- portfolio management services
- financial planning services

---

## Features

- **Premium 3D Hero Experience**: Engaging landing pages with custom 3D visuals.
- **Dark and Light Theme Support**: Full system-level and manual theme switching.
- **Contextual Audience Pages**: Tailored content for Schools, Colleges, Corporates, and Individuals.
- **Glassmorphism Design System**: Modern, Apple-like aesthetic with layered depth and blurs.
- **Responsive Design**: Flawless experience across mobile, tablet, and desktop devices.
- **SEO Optimized**: Advanced metadata, structured JSON-LD schema, and semantic HTML.
- **AEO Optimized**: Designed for AI Engine Optimization.
- **Accessibility Compliant**: Keyboard navigation, ARIA labels, and contrast compliance.
- **Google Forms Lead Capture**: Automated data collection (upcoming integration).
- **Google Sheets CRM**: Lead management system (upcoming integration).
- **Gmail Automation**: Automated email workflows.
- **PDF Delivery Workflow**: Secure asset downloads and tracking.

## Local Development

```bash

npm install

# Run the development server
npm run dev
```

Open: [http://localhost:3000](http://localhost:3000)

---

## Production Build

```bash
# Build the optimized production bundle
npm run build

# Start the production server
npm run start
```

---

## Repository Structure

- `/app`: The core Next.js App Router application.
  - `/src/app`: Page routes and layouts.
  - `/src/components`: Reusable UI components.
    - `/ui`: Atomic UI components (buttons, dialogs, form elements).
    - `/sections`: Page-level structural sections.
    - `/audience`: Specific components for the 4 primary audiences.
  - `/src/lib`: Utilities and configuration.
- `/docs`: Internal documentation, design systems, and strategy files.
- `/public`: Static assets, 3D icons, and downloadable resources.
